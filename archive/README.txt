白云山森林巡护管理系统
=======================

启动方式：
1. 安装 Python 依赖：pip install -r backend/requirements.txt
2. 启动后端：python backend/app.py
3. 浏览器打开 http://localhost:5051
4. 登录账号：admin / admin

手机护林员端：http://localhost:5051/mobile

子系统：
- 综合驾驶舱：实时态势总览
- 巡护监控与管理：实时巡护监控、覆盖分析、任务管理、力量台账
- 空间数据分析：火情/NDVI/FVC分析
- 灾害识别处置：火情/疫情AI识别、异常事件、风险预警
- 历史轨迹查询：多日巡护轨迹回放

数据库已预置6/28-7/3共6天约34万条历史巡护轨迹数据。
